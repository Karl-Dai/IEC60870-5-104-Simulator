# Windows 便携版更新

主站和子站的便携 EXE 使用独立的更新目标与签名，不下载或运行 NSIS/MSI 安装包。安装版仍使用安装包更新。

点击“立即安装”或选择下次启动安装后，便携版先下载并验证签名，再由辅助进程等待原进程退出，将新 EXE 放回原路径并启动。原文件名、所在目录和启动参数都会保留，重命名后的便携 EXE 也能更新。

替换文件或启动新程序失败时会恢复旧 EXE；辅助进程的工作目录中保留 `old.exe`、`new.exe` 和 `error.txt` 中仍适用的恢复文件。工作目录以 `.iec104-update-` 开头，位于便携 EXE 旁。更新成功后会自动清理。目录不可写、签名无效或发布清单缺少便携更新目标时会返回错误，不回退到安装包。

已发布的旧便携版不包含此更新逻辑。首次迁移需要手动下载包含此修复的 `*-portable.exe` 并替换旧文件，此后使用便携更新通道。

`cargo test --workspace` 在 Windows 上会运行隔离的原生辅助进程测试，验证退出后替换、中文及空格路径、重命名、启动参数和无效 EXE 回滚。测试程序不打开应用窗口。
